지난 포스팅에서 Vault HA를 구성하는 핵심 개념과 Leader Election, 데이터 복제(Data Replication), 그리고 Failover가 어떻게 이루어지는지 살펴봤습니다.

이를 바탕으로 Vault HA 클러스터를 직접 구축해보겠습니다.

실제 운영 환경에서는 일반적으로 여러 대의 물리 서버나 가상머신으로 클러스터를 운영합니다. 하지만 이러한 환경을 실습 목적으로 준비하려면 서버 구성이나 네트워크 설정 등 준비 과정이 다소 복잡해질 수 있습니다.

그래서 이번 실습에서는 Docker를 사용했습니다. Docker를 사용하면 비교적 간단하게 실습 환경을 준비하면서도 실제 운영 환경과 동일한 방식으로 Vault HA 클러스터를 구축할 수 있기 때문입니다.

---

## 1. 실습 환경

Vault HA에서 사용하는 Raft 알고리즘은 과반수(Quorum)를 기반으로 Leader를 선출합니다. 따라서 일반적으로 홀수 개의 노드로 클러스터를 구성하는 것이 권장됩니다. 

이번 실습에서는 3개의 Vault 컨테이너를 이용해 가장 단순한 형태의 HA 클러스터를 구축했습니다.

실습 환경은 다음과 같습니다.

| 구성 요소    | 내용                        |
| -------- | ------------------------- |
| OS     | Ubuntu 24.04 LTS          |
| Docker   | Docker Engine 29.3.0           |
| Vault    | HashiCorp Vault 1.21.4           |
| Storage  | Integrated Storage (Raft) |
| Network    | Docker Bridge Network     |


---

## 2. Docker 네트워크 생성

Vault HA 클러스터를 구성하려면 각 Vault 컨테이너가 서로 통신할 수 있어야 합니다. 각 노드는 Raft 프로토콜을 이용해 Leader Election을 수행하고 데이터를 복제하기 위해 지속적으로 다른 노드와 통신해야 합니다.

이를 위해 먼저 Vault 컨테이너들이 함께 사용할 Docker Bridge Network를 생성했습니다.

```bash
$ docker network create vault-network
```

네트워크가 정상적으로 생성되었는지 확인합니다.

```bash
$ docker network ls
```

실행 결과에서 `vault-network`가 조회되면 Docker 네트워크가 정상적으로 생성된 것입니다.

```nohighlight
NETWORK ID     NAME            DRIVER    SCOPE
xxxxxxxxxxxx   vault-network   bridge    local
```

이후 생성할 `vault-1`, `vault-2`, `vault-3` 컨테이너는 모두 `vault-network`에 연결하여 서로 통신할 수 있도록 설정합니다.

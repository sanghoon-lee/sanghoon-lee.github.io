ChatGPT의 도움을 받아서 GitHub Pages + Minima 테마로 심플한 블로그를 만들었습니다! 😄

<img class="main-image" src="/assets/images/githubpages.jpg" alt="GitHub Pages">

2-3년 전쯤, 이전에 근무하던 회사의 기술블로그를 GitHub에 만들면서 Jekyll 설정부터 Gem 설치까지 
이슈 해결을 구글링에 의존하면서 고생했던 기억이 아직도 생생합니다. 그런데 ChatGPT의 도움을
받으니 너무나 간단하네요.

## 블로그 컨셉

제가 원하는 블로그 컨셉은 다음과 같았습니다.

* 가볍고 심플한 디자인
* 포스팅 기능에 충실

너무 단순하죠? 복잡하게 꾸미지 말고, 글 쓰기에 충실한 블로그를 만들고 싶었어요. 이러한 조건에 딱 맞는 것이 GitHub Pages의 공식 추천 테마 중 하나인 Minima였습니다.

## 블로그 생성

사실 GitHub Pages에 블로그를 만들어서 운영하는 것은 쉬운 일은 아니었습니다. 어느정도 개발지식이 필요했던 것은 사실이었죠. 하지만, ChatGPT의 도움으로 생각보다 쉽고 빠르게 원하는 형태로 블로그를 만들 수 있었습니다.

ChatGPT가 알려준 방식대로 GitHub에 리포지토리 생성하고, 필요한 초기 설정 파일들도 작성해서 업로드했습니다. 그리고 ChatGPT와 대화하면서 요구사항을 이야기했어요. 그러면 그에 맞는 코드를 ChatGT가 만들어서 보여줍니다. 리포지토리에 그 코드를 업로드하고, 확인만 하면 끝입니다. 물론, 마음에 들지 않거나 의도와 다르게 구현한 부분도 있어서 ChatGPT한테 몇 차례 수정요청은 필요했습니다. 요즘 관심이 높은 바이브 코딩 방식입니다.

마치 제 옆에 개발자 1명이 있는 것 같았어요. LLM의 출현으로 이제는 개발지식이 없어도 아이디어만 있으면 충분한 세상이 되어 버린 것 같습니다. 코드 구현은 LLM이 얼마든지 할 수 있으니까요.

## 블로그 운영

얼마전부터 운영하고 있는 네이버 블로그에는 일상의 이야기를 주로 포스팅하고, 이번에 만든 GitHub 블로그에는 개발팀장으로 일하면서 배우고, 느낀 점들을 체계적으로 정리해서 포스팅해보려고 합니다. 업무와 관련된 실험적인 아이디어와 가볍게 떠올랐던 생각도 포스팅하고요. 이런 것들이 모이면 저의 소중한 지식 자산이 되지 않을까요? 부족함이 많았던 어느 개발팀장의 성장기록으로도 가치는 있을 것 같고요.

ChatGPT의 도움을 받아서 GitHub Pages + Minima 테마로 심플한 블로그를 만들었습니다! 😄

<img class="main-image" src="/assets/images/githubpages.jpg" alt="GitHub Pages">

2-3년 전쯤 회사에서 GitHub에 기술 블로그를 만들면서 고생했던 기억이 아직도 생생합니다.

Jekyll 설정부터 Gem 설치까지 해결해야 할 이슈가 너무 많았습니다.

그런데 이번에는 ChatGPT의 도움을 받으니 너무 쉬웠습니다.

---

## 1. 블로그 컨셉

제가 원하는 블로그 컨셉은 다음과 같았습니다.

* 가볍고 심플한 디자인
* 포스팅 기능에 충실

너무 단순한가요? 복잡하게 꾸미지 말고, 글 쓰기에 충실한 블로그를 만들고 싶었습니다. 이러한 조건에 딱 맞는 것이 GitHub Pages의 공식 추천 테마 중 하나인 Minima였습니다.

---

## 2. 블로그 생성

사실 GitHub Pages에 블로그를 만들어서 운영하는 것은 쉬운 일은 아닙니다. 하지만 ChatGPT의 도움을 받으면 생각보다 쉽고 빠르게 원하는 형태로 블로그를 만들 수 있습니다.

사람과 대화하듯이 요구사항을 이야기하면 그에 맞는 코드와 설정 파일들을 ChatGPT가 생성해서 보여주게 됩니다. GitHub 저장소(Repository)에 ChatGPT가 생성해 준 코드와 설정 파일들을 업로드하고 확인만 하면 끝입니다. 

물론, 마음에 들지 않거나 원래 의도와 다르게 구현된 부분이 있어서 몇 차례 수정 요청하는 절차는 필요했습니다. 

마치 제 옆에 개발자 1명이 있는 것 같았어요. AI 기술의 발전으로 이제는 개발지식이 없더라도 아이디어만 있으면 충분한 세상이 되어 버린 것 같습니다. 코드 구현은 AI가 얼마든지 할 수 있는 세상이 되었으니까요.

---

## 3. 블로그 운영

이번에 만든 블로그에 개발팀장으로 일하면서 배우고, 느낀 점들을 체계적으로 정리해서 포스팅해보려고 합니다. 

물론, 업무와 관련된 실험적인 아이디어와 가볍게 떠올랐던 생각을 정리하는 것도 포함입니다. 

이런 것들이 모이면 저만의 소중한 지식 자산이 되지 않을까요? 부족함이 많았던 어느 개발팀장의 성장기록으로 가치는 있을 것 같습니다.

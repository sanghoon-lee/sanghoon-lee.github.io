ChatGPT의 도움을 받아서 GitHub Pages + Minima 테마로 심플한 블로그를 만들었습니다! 😄

<img class="main-image" src="/assets/images/githubpages.jpg" alt="GitHub Pages">

2-3년 전쯤 회사에서 GitHub에 기술 블로그를 만들면서 고생했던 기억이 아직도 생생합니다.

당시에는 Jekyll 설정부터 Gem 설치까지 해결해야 할 이슈가 너무 많았습니다. 구글링에 의존해서 겨우 해결은 할 수 있었습니다. 하지만, 쉽지는 않았습니다.

그런데 이번에 ChatGPT의 도움으로 생각보다 쉽고 빠르게 원하는 형태로 블로그를 만들 수 있습니다.

---

## 1. 블로그 컨셉

제가 원하는 블로그 컨셉은 다음과 같습니다.

* 가볍고 심플한 디자인
* 포스팅 기능에 충실

너무 단순한가요? 그냥 글 쓰기에 충실한 블로그를 만들고 싶을 뿐입니다. 

이러한 조건에 딱 맞는 것이 GitHub Pages의 공식 추천 테마 중 하나인 **Minima**입니다.

---

## 2. 블로그 생성

테마를 선택한 다음에는 ChatGPT에게 대화하는 것처럼 요구사항을 이야기하면 됩니다.

어려운 기술적 용어를 사용하지 않아도 됩니다. 

ChatGPT가 요구사항에 맞는 코드와 설정 파일등을 생성해주면 확인하고, GitHub 저장소(Repository)에 업로드하면 끝입니다.  

바로 옆에 개발자 1명이 있는 것 같습니다. 

마음에 들지 않거나 원래 의도와 다르게 구현된 부분이 있으면 수정 요청을 하면 됩니다.

이제는 개발에 대한 지식이 없더라도 AI의 도움을 받아 코드로 구현 가능한 세상이 되어 버린 것 같습니다. 

---

## 3. 블로그 운영

이번에 만든 블로그에 개발팀장으로 일하면서 배우고 느낀 점들을 정리해서 포스팅하려고 합니다. 

물론, 업무를 하면서 떠올랐던 실험적인 아이디어와 짧은 생각들도 포함입니다. 

이런 기록들이 모이면 저만의 소중한 지식 자산이 되지 않을까요? 부족함이 많았던 어느 개발팀장의 성장기록으로 가치는 있을 것 같습니다.

ChatGPT의 도움을 받아서 GitHub Pages + Minima 테마로 심플한 블로그를 만들었습니다! 😄

<img class="main-image" src="/assets/20251128/githubpages.jpg" alt="GitHub Pages">

2-3년 전쯤, 이전에 근무하던 회사의 기술블로그를 GitHub에 만들면서 Jekyll 설정부터 Gem 설치까지 
이슈 해결을 구글링에 의존하면서 고생했던 기억이 아직도 생생합니다. 그런데 ChatGPT의 도움을
받으니 너무나 간단하네요.

## 블로그 컨셉

제가 원하는 블로그 컨셉은 다음과 같았습니다.

* 가볍고 심플한 디자인
* 포스팅 기능에 충실

너무 단순하죠? 복잡하게 꾸미지 말고, 글 쓰기에 충실한 블로그를 만들고 싶었어요. 이러한 조건에 딱 맞는 것이 GitHub Pages의 공식 추천 테마 중 하나인 Minima였습니다.

## 블로그 생성

GitHub에 리포지토리 생성하고, 바이브 코딩을 하는처럼 ChatGPT와 대화하면서 원하는 형태의 블로그를
만들 수 있었습니다. 제가 요구사항을 이야기하면, 그에 맞는 코드는 ChatGPT가 만들었어요.
리포지토리에 그 코드를 업로드하고, 확인만 하면 되니까 정말 편했습니다. 당연히 마음에 들지 않거나, 의도와 다르게
구현된 부분도 있어서 ChatGPT한테 몇 차례 수정해달라고 요청했고요. 

제 옆에 개발자 1명이 있는 것 같았어요. LLM의 출현으로 이제는 개발지식이 없어도 아이디어만 있으면 충분한 세상이 되어 버린 것 같아요.
코드는 LLM이 얼마든지 생성해줄 수 있으니까요.

## 블로그 운영

GitHub 블로그에는 앞으로 개발팀장으로 일하면서 배우고, 느낀 점들을 체계적으로 정리해서 글로 남겨보려고 합니다.
실험적인 아이디어와 가볍게 떠오르는 생각도 포함해서요. 이런 것들이 모여서, 부족함이 많았던 어느 개발팀장의 성장기록이 되겠지요.

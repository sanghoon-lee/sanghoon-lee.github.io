이번 실습은 Oracle VM으로 생성한 가상머신 환경에서 진행했습니다.

Reverse Proxy는 NginX를 이용하여 구성하고, 요청을 처리할 애플리케이션 서버는 Spring Boot로 구현했습니다.

실습 환경은 다음과 같습니다.

* Oracle VM(Ubuntu Linux)
* Docker
* Spring Boot API 애플리케이션(애플리케이션 서버)
* NginX

이번 포스팅에서는 Reverse Proxy 구성에 앞서 요청을 처리할 애플리케이션 서버를 먼저 구현하고, Docker 컨테이너로 실행하는 과정까지 정리해보려고 합니다.

Oracle VM에서 가상머신을 생성하고 Docker를 설치하는 과정은 이미 완료된 상태라고 가정합니다.

---

## 1. 애플리케이션 서버 구현

실습을 위해서는 Reverse Proxy로부터 요청을 전달받아 이를 처리할 애플리케이션 서버가 필요합니다.

그래서 Java 기반 프레임워크인 Spring Boot로 애플리케이션 서버를 직접 구현했습니다.

물론, 실제 운영 환경에서는 다양한 기능이 포함된 애플리케이션 서버가 사용될 것입니다.

하지만 이번 학습의 목적은 Reverse Proxy의 동작을 확인하는 것이므로, 애플리케이션 서버의 기능 구현 범위는 요청을 수신하고 응답을 반환하는 단순한 API로 최소화했습니다.

---

### 1.1. 프로젝트 생성

프로젝트 생성 정보는 다음과 같습니다.

* Project: Gradle-Groovy
* Language: Java
* Spring Boot: 3.5.14
* Group: sanghoon.study
* Artifact: simple-api
* Packaging: Jar
* Java: 17

의존성은 REST API 구현에 필요한 Spring Web만 추가했습니다.

---

### 1.2. API 정의

애플리케이션 서버는 Reverse Proxy로부터 전달받은 요청을 처리할 수 있어야 합니다.

이번 실습에서는 요청을 처리한 서버의 이름과 시간을 반환하는 간단한 API를 구현했습니다.

요청 형식은 다음과 같습니다.

**요청**
```bash
GET /api/server HTTP/1.1
```

**응답 예시**
```json
{
    "serverName":"api-01",
    "time":"2026-06-05T20:50:34.578004200"
}
```

이 API를 통해 여러 개의 애플리케이션 서버가 동작하는 환경에서도 어떤 서버가 요청을 처리했는지 쉽게 확인할 수 있습니다.

---

### 1.3. 프로젝트 구조

애플리케이션 서버의 프로젝트 구조는 다음과 같습니다.

```text
src 
 └─ main 
     ├─ java 
     │   └─ sanghoon.study.simpleapi 
     │      ├─ SimpleApiApplication.java 
     │      └─ controller
     │          └─ ApiController.java  
     └─ resources 
         └─ application.yaml
```

프로젝트는 최대한 단순한 구조로 구성했습니다.

이번 실습에서는 앞에서 정의한 API만 제공하면 되므로 별도의 Service나 Repository 계층은 생성하지 않았습니다.

API 요청을 처리하는 ApiController 클래스와 애플리케이션 설정을 위한 application.yaml 파일만 생성했습니다.

---

### 1.4. ApiController 클래스

ApiController 클래스는 /api/server 요청을 처리하도록 구현했습니다.

요청이 수신되면 서버 이름과 현재 시간을 응답으로 반환합니다. 서버 이름은 SERVER_NAME 환경변수를 통해 전달받은 값을 사용하도록 구성했습니다.

이후 Reverse Proxy의 로드밸런싱 기능을 확인하기 위해 동일한 애플리케이션 서버를 여러 개 실행할 예정입니다. 응답에 포함된 서버 이름을 통해 어떤 서버가 요청을 처리했는지 확인할 수 있습니다.

**ApiController.java**
```java
package sanghoon.study.simpleapi.controller;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.time.LocalDateTime;
import java.util.Map;

@RestController
@RequestMapping("/api")
public class ApiController {
    @Value("${SERVER_NAME:unknown}")
    private String serverName;

    @GetMapping("/server")
    public Map<String, String> server() {
        return Map.of(
                "serverName", serverName,
                "time", LocalDateTime.now().toString()
        );
    }
}
```

---

### 1.5. 설정 파일

Spring Boot의 기본 포트는 8080입니다.

이번 실습에서는 애플리케이션 서버의 포트를 8000으로 사용하도록 구성했습니다. 그래서 application.yaml 파일을 다음과 같이 작성했습니다.

**application.yaml**
```yaml
server:
  port: 8000
```

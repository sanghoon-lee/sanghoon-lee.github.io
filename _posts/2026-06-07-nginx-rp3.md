애플리케이션 서버가 클라이언트의 요청을 정상적으로 처리할 수 있는 상태가 되었습니다.

이제 Nginx를 설치해서 Reverse Proxy 서버로 동작할 수 있도록 구성해야 합니다.

구성이 완료되면 Nginx가 클라이언트의 요청을 먼저 수신한 뒤 내부 애플리케이션 서버로 전달하는 구조를 만들 수 있습니다.

이번 포스팅에서는 Nginx 설치하고 Reverse Proxy로 동작할 수 있도록 설정하는 과정을 단계별로 살펴보도록 하겠습니다.

---

## 1. Nginx 설치

Nginx를 컨테이너로 실행하면 설치와 제거가 간편하고 설정 변경이나 재구성도 쉽게 수행할 수 있습니다. 

또한 애플리케이션 서버와 동일한 방식으로 관리할 수 있어 실습 환경을 구성하기에도 편리합니다. 그래서 Nginx도 Docker 컨테이너로 실행했습니다.

먼저 Docker Hub에서 최신버전의 Nginx 이미지를 내려받았습니다.

```bash
$ docker pull nginx
```

다운로드가 완료되고, 저장되어 있는 Docker 이미지 목록을 조회했습니다. 애플리케이션 서버(simple-api)와 nginx 이미지가 존재하는 것을 확인할 수 있었습니다.

```bash
$ docker images
```

```nohighlight
IMAGE               ID             DISK USAGE   CONTENT SIZE   EXTRA
nginx:latest        5aca99593157        241MB           66MB
simple-api:latest   50ac61d202ac        465MB          128MB    U
```

## 2. Reverse Proxy 기본 설정

Nginx는 설정 파일을 통해 요청을 어떤 서버로 전달할지 정의할 수 있습니다. 그래서 설정 파일을 저장할 디렉토리를 먼저 생성했습니다.

```bash
$ mkdir nginx
$ cd nginx
```

그리고 nginx.conf 파일을 생성하고 다음과 같이 작성했습니다.

**nginx.conf**

```nohighlight
events {
}

http {

    server {

        listen 80;

        location / {
            proxy_pass http://192.168.56.11:8001;
        }
    }
}
```

설정 내용은 매우 단순합니다.

* `listen 80` : Nginx가 80 포트를 사용해서 클라이언트의 요청을 수신합니다.
* `location /` : 모든 요청을 대상으로 설정합니다.
* `proxy_pass` : 수신한 요청을 애플리케이션 서버 컨테이너가 구동되고 있는 주소(192.168.56.11:8001)로 전달합니다. 클라이언트는 애플리케이션 서버의 주소를 직접 알 필요가 없으며, 모든 요청은 Reverse Proxy를 통해 전달됩니다.

> 현재 애플리케이션 서버 컨테이너는 nginx와 동일한 가상머신에서 구동되고 있습니다. 가상머신의 8001 포트로 노출되어 있으므로 `proxy_pass`에 해당 주소를 지정했습니다.

## 3. Nginx 컨테이너 실행

Nginx는 실행 시 기본 설정 파일을 읽어 동작합니다. 

따라서 앞에서 작성한 nginx.conf 파일을 컨테이너 내부의 설정 파일 위치로 연결(Mount)하도록 다음과 같이 컨테이너를 실행해야 합니다.

```bash
$ docker run -d \
  --name nginx-rp \
  -p 80:80 \
  -v {경로}/nginx.conf:/etc/nginx/nginx.conf:ro \
  nginx
```

`{경로}`에는 실제 설정 파일이 존재하는 디렉토리로 지정해야 합니다. 제가 사용하는 가상머신의 디렉토리는 `/home/sanghoon/nginx`입니다.

컨테이너 실행에 사용한 각 옵션의 의미는 다음과 같습니다.

* `-d` : 컨테이너를 백그라운드에서 실행합니다.
* `--name nginx-rp` : 컨테이너 이름을 nginx-rp로 지정합니다.
* `-p 80:80` : 가상머신의 80 포트와 컨테이너의 80 포트를 연결합니다.
* `-v` : 로컬의 nginx.conf 파일을 컨테이너 내부 설정 파일로 연결합니다.
* `:ro` : 설정 파일을 읽기 전용(Read Only)으로 마운트합니다.
* `nginx` : 실행할 Docker 이미지입니다.

컨테이너가 정상적으로 실행되는지 확인했고, Nginx 컨테이너와 애플리케이션 서버 컨테이너가 모두 실행 중인 것을 확인할 수 있었습니다.

```bash
$ docker ps
```


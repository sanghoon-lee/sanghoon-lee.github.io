애플리케이션 서버 컨테이너를 실행해서 클라이언트의 요청을 정상적으로 처리할 수 있는 상태가 되었습니다.

현재는 애플리케이션 서버만 실행된 상태이기 때문에 클라이언트가 애플리케이션 서버에 직접 접근할 수 있습니다.

이제 Nginx를 설치하여 Reverse Proxy를 구성하고, 클라이언트의 요청이 Nginx를 거쳐 애플리케이션 서버로 전달되도록 구조를 변경해보겠습니다.

---

## 1. Nginx 도커 이미지 준비

Nginx를 컨테이너로 실행하면 설치와 제거가 간편하고 설정 변경이나 재구성도 쉽게 수행할 수 있습니다. 

또한 애플리케이션 서버와 동일한 방식으로 관리할 수 있어 실습 환경을 구성하기에도 편리합니다. 그래서 Nginx도 Docker 컨테이너로 실행했습니다.

먼저 Docker Hub에서 최신버전의 Nginx 이미지를 내려받았습니다.

```bash
$ docker pull nginx
```

다운로드가 완료되고, 저장되어 있는 Docker 이미지 목록을 조회했습니다. 애플리케이션 서버(simple-api)와 nginx 이미지가 존재하는 것을 확인할 수 있었습니다.

```bash
$ docker images
```

```nohighlight
IMAGE               ID             DISK USAGE   CONTENT SIZE   EXTRA
nginx:latest        5aca99593157        241MB           66MB
simple-api:latest   50ac61d202ac        465MB          128MB    U
```

## 2. Nginx 설정 

Nginx 설정 파일을 관리하기 위해 디렉터리를 생성했습니다.

```bash
$ mkdir nginx
$ cd nginx
```

그리고 Reverse Proxy로 동작할 수 있도록 nginx.conf 파일을 생성하고 다음과 같이 작성했습니다.

**nginx.conf**

```nohighlight
events {
}

http {
    server {

        listen 80;

        location / {
            proxy_pass http://192.168.56.11:8001;
        }
    }
}
```

설정 내용은 매우 단순합니다.

* `listen 80` : Nginx가 80 포트를 사용해서 클라이언트의 요청을 수신합니다.
* `location /` : 모든 요청을 대상으로 설정합니다.
* `proxy_pass` : 수신한 요청을 애플리케이션 서버의 주소(192.168.56.11:8001)로 전달합니다.

현재는 Nginx와 애플리케이션 서버가 동일한 가상머신에서 실행되고 있기 때문에 가상머신의 IP와 포트를 사용했습니다.

---

## 3. Nginx 컨테이너 실행

앞에서 작성한 nginx.conf 파일을 컨테이너 내부 설정 파일 경로에 마운트하여 실행했습니다.

```bash
$ docker run -d \
  --name nginx-rp \
  -p 80:80 \
  -v {경로}/nginx.conf:/etc/nginx/nginx.conf:ro \
  nginx
```

`{경로}`에는 실제 설정 파일이 존재하는 디렉토리로 지정해야 합니다. 제가 사용하는 가상머신의 디렉토리는 `/home/sanghoon/nginx`입니다.

컨테이너 실행에 사용한 각 옵션의 의미는 다음과 같습니다.

* `-d` : 컨테이너를 백그라운드에서 실행합니다.
* `--name nginx-rp` : 컨테이너 이름을 nginx-rp로 지정합니다.
* `-p 80:80` : 가상머신의 80 포트와 컨테이너의 80 포트를 연결합니다.
* `-v` : 로컬의 nginx.conf 파일을 컨테이너 내부 설정 파일로 연결합니다.
* `:ro` : 설정 파일을 읽기 전용(Read Only)으로 마운트합니다.
* `nginx` : 실행할 Docker 이미지입니다.

컨테이너가 정상적으로 실행되는지 확인했고, Nginx 컨테이너와 애플리케이션 서버 컨테이너가 모두 실행 중인 것을 확인할 수 있었습니다.

```bash
$ docker ps
```

```nohighlight

2bd57b3e33a6   nginx        "/docker-entrypoint.…"   5 minutes ago   Up 5 minutes   0.0.0.0:80->80/tcp, [::]:80->80/tcp           nginx-rp

```

클라이언트의 요청이 Nginx를 통해 애플리케이션 서버로 정상적으로 전달되는지 확인했습니다. 정상적인 응답이 반환되었습니다.

설정을 완료한 뒤에는 클라이언트의 요청이 Nginx를 거쳐 내부 애플리케이션 서버로 정상적으로 전달되는 것을 확인할 수 있었습니다.
